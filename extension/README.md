# Quota Codex bridge

Extension Chromium Manifest V3 utilisée par l’application macOS Quota Codex.

Elle lit uniquement les limites visibles sur la page <https://chatgpt.com/codex/settings/usage> et les transmet à l’application locale via `http://127.0.0.1:48721/quota`. Elle ne demande aucun accès aux cookies, mots de passe ou données de stockage.

Pour l’installation complète, consulte [le guide principal](../docs/INSTALLATION.md).
